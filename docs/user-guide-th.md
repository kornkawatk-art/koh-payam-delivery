# คู่มือการใช้งาน — แอปส่งสินค้าเกาะพยาม (สำหรับทีมสาขา)

คู่มือนี้อธิบายทุกหน้าจอและขั้นตอนการทำงานประจำวัน ตั้งแต่นำเข้าออเดอร์ตอนเช้าจนส่งขึ้นเรือและเคลียร์เคลม
หน้าจอทีมงานเป็น **ภาษาไทย** ทั้งหมด ส่วนหน้าที่ลูกค้าเห็นเป็นภาษาอังกฤษ (สลับไทยได้)

เปิดแอปผ่านเบราว์เซอร์บนมือถือ / แท็บเล็ต / คอม — เพิ่มลงหน้าจอโฮมได้เพื่อกดเปิดเร็ว ๆ

---

## 1. บทบาทในทีม

| บทบาท | ทำอะไรได้ |
|---|---|
| **คนแพ็ค** | ดูงานวันนี้, นำเข้าออเดอร์, หน้าแพ็ค, พิมพ์ใบเขียนหน้าลัง, เปิดดูรายละเอียดออเดอร์ |
| **คนที่ท่าเรือ** | ดูงานวันนี้, ตั้งค่าเรือประจำวัน, หน้าท่าเรือ (เลือกเรือ + แนบรูป + ส่งขึ้นเรือ), เปิดดูรายละเอียดออเดอร์ |
| **หัวหน้า** | ทำได้ทุกอย่างข้างบน **+ คิวเคลมและการอนุมัติเคลม** (เฉพาะหัวหน้าเท่านั้นที่อนุมัติ/ปฏิเสธเคลมได้) |

ถ้าเมนูที่ควรเห็นไม่ขึ้น แปลว่าบทบาทของบัญชียังไม่ถูกตั้ง — แจ้งหัวหน้า (ดูคู่มือดูแลระบบ ส่วน C)

---

## 2. เข้าสู่ระบบ + ตั้งยืนยันตัวตนสองชั้น (2FA) ครั้งแรก

**ต้องมีแอป Authenticator บนมือถือก่อน** (เช่น Google Authenticator, Microsoft Authenticator, Authy) — โหลดจาก App Store / Play Store

1. เปิดแอป → หน้า **เข้าสู่ระบบทีมงาน** → กรอกอีเมล + รหัสผ่านที่หัวหน้าให้มา
2. ครั้งแรกระบบจะพาไปหน้า **ตั้งค่ายืนยันตัวตนสองชั้น**
   - เปิดแอป Authenticator บนมือถือ → กดเพิ่มบัญชี → **สแกน QR code** ที่ขึ้นบนจอ
   - แอป Authenticator จะแสดงรหัส 6 หลักที่เปลี่ยนทุก 30 วินาที
   - พิมพ์รหัส 6 หลักนั้นลงในแอป → กดยืนยัน
3. เข้าใช้งานครั้งต่อ ๆ ไป: กรอกอีเมล + รหัสผ่าน → แล้วกรอกรหัส 6 หลักจากแอป Authenticator ทุกครั้ง

> ทำมือถือหาย / ลบแอป Authenticator = ล็อกอินไม่ได้ ต้องให้หัวหน้าลบ "MFA factor" ใน Supabase ให้ แล้วตั้ง 2FA ใหม่ (ดูคู่มือดูแลระบบ)

## 3. งานวันนี้ (แดชบอร์ดรายวัน)

หน้าแรกหลังล็อกอิน — สรุปงานส่งของวันนั้นทั้งหมด มีช่องเลือกวันที่มุมขวาบน (ย้อนดู/ล่วงหน้าวันอื่นได้)

- **แถบความคืบหน้า:** "แพ็คแล้ว X/ทั้งหมด · ถึงท่าเรือ Y · ส่งแล้ว Z"
- **แถบเตือนของค้างส่ง** (สีเหลือง): ถ้ามีของค้างส่งจากวันก่อนที่ต้องส่งวันนี้ จะขึ้น "ของค้างส่ง N รายการรอส่งวันนี้" พร้อมลิสต์ออเดอร์ต้นทาง
- **ตารางออเดอร์:** เลขออเดอร์ / ลูกค้า / สถานะ / **รวม** (ลังกระดาษ+ลังโฟม+ชิ้น รวมกัน) / เรือ — กดแถวเพื่อเข้าหน้ารายละเอียดออเดอร์
  - ป้าย **"เก็บเงิน"** สีเหลืองข้างสถานะ = ออเดอร์นี้ยังมียอดค้างชำระ (ดูจำนวนเงินที่หน้ารายละเอียดออเดอร์)
  - ป้าย **"หลาย PO"** = ลูกค้าคนนี้มีออเดอร์อื่นส่งวันเดียวกันด้วย (จับคู่ด้วยเบอร์โทร) — ลูกค้าจะเห็นและสลับไปดูกันเองได้จากหน้าออเดอร์
- **ช่องค้นหา:** พิมพ์ชื่อลูกค้า หรือเลขออเดอร์ เพื่อกรอง

สถานะออเดอร์ไล่จากซ้ายไปขวา (4 ขั้น):
`นำเข้าแล้ว → แพ็คเสร็จ → ถึงท่าเรือ → ส่งแล้ว`
(ไม่มีขั้น "ลูกค้ายืนยันรับของ" — จบที่ "ส่งแล้ว")

## 4. นำเข้าออเดอร์ (ต้นวัน)

เมนู **นำเข้าออเดอร์** (คนแพ็ค / หัวหน้า) — ต้องใช้ **2 ไฟล์จากระบบแม็คโคร**

1. **Export 2 ไฟล์จากระบบแม็คโคร** (วันนั้น):
   - **OrderDetailExport** — ไฟล์รายการสินค้าต่อบรรทัด (สั่ง/ส่งจริง/ของขาด ต่อ item)
   - **OrderExport** — ไฟล์ระดับออเดอร์ มีที่อยู่จัดส่ง + ข้อมูลการชำระเงิน
2. อัปโหลดทั้ง 2 ไฟล์ลงช่องของมัน — **"ไฟล์รายการสินค้า (OrderDetailExport)"** และ **"ไฟล์ที่อยู่ (OrderExport)"**
   - ถ้าเอาไฟล์ไปวางผิดช่อง (เช่น เอา OrderExport ไปวางช่องรายการสินค้า) ระบบจะเตือนทันทีว่าไฟล์ไม่ตรงช่อง
3. **จับคู่คอลัมน์ (ครั้งแรกครั้งเดียวต่อไฟล์):** มี 2 ชุดแยกกัน — "จับคู่คอลัมน์ — รายการสินค้า" กับ "จับคู่คอลัมน์ — ที่อยู่" ระบบเดาคอลัมน์ให้อัตโนมัติตามชื่อคอลัมน์จริงของแม็คโครอยู่แล้ว (ปกติไม่ต้องแก้)
   - ระบบ **จำการจับคู่ไว้ในเบราว์เซอร์** — ครั้งต่อไปไม่ต้องตั้งใหม่ (ถ้าใช้เครื่อง/เบราว์เซอร์เดิม)
   - ถ้ารูปแบบไฟล์แม็คโครเปลี่ยน หรือคอลัมน์เพี้ยน ให้แก้การจับคู่ใหม่ตรงนี้
4. กด **ดูตัวอย่าง** — ระบบจะ:
   - **กรองเฉพาะออเดอร์ที่ส่งเกาะพยามอัตโนมัติ** (ตำบล = "เกาะพยาม" หรือที่อยู่มีคำว่า "ไต๋แขก"/"Taikak") ออเดอร์อื่นถูกข้ามไปโดยไม่นำเข้า
   - แสดง "เจอออเดอร์เกาะพยาม N เจ้า" พร้อมตารางตัวอย่าง (เลขออเดอร์ / ลูกค้า / จำนวนรายการ / จำนวนของขาด)
   - เตือนถ้ามีออเดอร์ที่มีที่อยู่แต่หารายการสินค้าไม่เจอ ("ข้าม N ออเดอร์...")
   - เตือนถ้าไฟล์ยังไม่มีข้อมูลส่งจริงจากแม็คโคร (ส่งจริง = 0 ทั้งหมด) — นำเข้าได้ แต่ควร export ใหม่หลังจัดของเสร็จ
5. ตรวจ/แก้ **วันจัดส่ง** (ระบบตั้งให้อัตโนมัติจากวันที่คาดว่าจะได้รับในไฟล์ แก้เองได้)
6. กด **นำเข้า N ออเดอร์**

**นำเข้าซ้ำ (sync) ไม่ทำลายข้อมูล:** ถ้าเลขออเดอร์ในไฟล์ตรงกับที่เคยนำเข้าไปแล้ว ระบบจะ **อัปเดตข้อมูลจากแม็คโครให้อัตโนมัติ** (ชื่อลูกค้า/ที่อยู่/รายการสินค้า/ยอดค้างชำระ) โดย **ไม่แตะ** สถานะ, เรือที่เลือก, จำนวนลังที่กรอก, รูปหลักฐาน, ลิงก์ลูกค้า, หรือเคลมที่มีอยู่แล้ว — นำเข้าไฟล์เดิมซ้ำได้เรื่อย ๆ อย่างปลอดภัย (เช่น export ใหม่ตอนบ่ายหลังยอดชำระเงินเปลี่ยน) ผลลัพธ์ขึ้นเป็น "นำเข้า X ใหม่ · sync Y"

## 5. หน้าแพ็ค (รายออเดอร์)

จากงานวันนี้ กดออเดอร์ → **แพ็คของ**

- **ของค้างส่งจากออเดอร์ก่อนหน้า:** ถ้าลูกค้ารายนี้มีของค้างจากวันก่อน จะขึ้นกล่องเตือนด้านบน "ของค้างส่งจากออเดอร์ก่อนหน้า" — จัดของกลุ่มนี้ใส่ไปด้วย แล้วกด "ส่งแล้ว" ที่รายการนั้น
- **รายการสินค้า (อ่านอย่างเดียว):** รหัสสินค้า / ชื่อสินค้า / จำนวนสั่ง / จำนวนส่งจริง / หมายเหตุ — ตัวเลข "ส่งจริง" และของขาด (ป้าย "ขาด") มาจากไฟล์แม็คโครโดยตรง **ไม่ต้องติ๊กเอง** ระบบสร้างรายการค้างส่งให้อัตโนมัติจากของขาดที่แม็คโครระบุ (ดูข้อ 11)
- **จำนวนลัง/ชิ้น:** กรอก **ลังกระดาษ** กี่ใบ, **ลังโฟม** กี่ใบ, และ **จำนวนชิ้น** (สินค้าที่ไม่ได้แพ็คใส่ลัง นับเป็นชิ้นแยกต่างหาก) — ใต้ช่องกรอกมีสรุป **"ลังกระดาษ N · ลังโฟม N · ชิ้น N · รวม N"** ให้เห็นยอดรวมทันที
  - แตะเข้าช่องไหน ตัวเลขเดิม (ปกติเป็น 0) จะถูกเลือกไว้ให้อัตโนมัติ พิมพ์ทับได้เลยไม่ต้องลบก่อน
- **รูปหลักฐานตอนแพ็ค:** ถ่ายรูปกองลังที่แพ็คเสร็จด้วยกล้องมือถือก่อน แล้วกด **"แนบรูป"** เพื่อเลือกรูปที่เพิ่งถ่ายมาแนบ (ไม่จำกัดจำนวน)
- ปุ่ม **บันทึก** — บันทึกจำนวนลัง/ชิ้น + รูปที่แนบไว้ กดได้เสมอ (ยังแพ็คไม่เสร็จก็บันทึกความคืบหน้าได้)
- ปุ่ม **บันทึก + แพ็คเสร็จ** — เปลี่ยนสถานะเป็น "แพ็คเสร็จ"

> **⚠️ ปุ่ม "บันทึก + แพ็คเสร็จ" กดไม่ได้จนกว่าจะครบ 2 อย่าง:** (1) มีรูปหลักฐานตอนแพ็คอย่างน้อย **1 รูป** และ (2) กรอก**ลังกระดาษ+ลังโฟมรวมกัน**อย่างน้อย **1 ลัง** (จำนวนชิ้นไม่นับรวมในเงื่อนไขนี้) ถ้ายังไม่ครบจะมีข้อความ *"ต้องถ่ายรูปลังที่แพ็คเสร็จอย่างน้อย 1 รูป และกรอกจำนวนลังอย่างน้อย 1 ลัง"* ขึ้นใต้ปุ่ม — ปุ่ม "บันทึก" เฉย ๆ ไม่ติดเงื่อนไขนี้

> **ของขาด → สร้างรายการค้างส่งอัตโนมัติ:** ทุกรายการที่แม็คโครระบุว่าส่งไม่ครบ (ป้าย "ขาด") ระบบจะสร้างรายการค้างส่ง (backorder) ผูกกับวันจัดส่งถัดไปของลูกค้ารายนั้นให้เอง แล้วไปโผล่ในหน้าแพ็คของวันนั้น ไม่ต้องจดเอง

## 6. ใบเขียนหน้าลัง

จากหน้ารายละเอียดออเดอร์ หรือหน้าแพ็ค → **ใบเขียนหน้าลัง** → กด **สั่งพิมพ์** (Ctrl/Cmd + P หรือปุ่มพิมพ์ของเบราว์เซอร์)

- ใบจะแสดง **ชื่อลูกค้าตัวใหญ่** + เลขกำกับ (เช่น 1/5 ถึง 5/5) แยก 3 ชุด: ลังกระดาษ / ลังโฟม / **ชิ้น** (ถ้ามี) — ของที่ไม่ได้แพ็คใส่ลังก็เขียนเลขกำกับติดตัวเหมือนกัน
- ทีมเขียนหน้าลังจริงด้วย **ปากกาเคมี** ตามใบ (ไม่ใช้สติกเกอร์ — หลุดง่ายบนลังโฟม/บนเรือ)

## 7. ตั้งค่าเรือประจำวัน (ต้นวัน — คนท่าเรือ / หัวหน้า)

เมนู **ตั้งค่าเรือประจำวัน** — มีช่องเลือกวันที่มุมขวาบน (ตั้งเรือของวันอื่นล่วงหน้าได้)

- วันใหม่จะมีค่าเริ่มต้น เรือ 1 / เรือ 2 / เรือ 3 ให้อัตโนมัติ
- กด **+ เพิ่มเรือ** เพื่อเพิ่ม, กด **ลบ** ข้างเรือที่ไม่ใช้, แก้ชื่อเรือได้ (เช่น "เรือเจ๊แดง")
- กด **บันทึก**
- **ลบเรือที่มีออเดอร์ผูกอยู่ไม่ได้** — ถ้าลองลบจะขึ้น "ลบไม่ได้: มี N ออเดอร์ผูกกับเรือนี้แล้ว" ต้องไปเปลี่ยนเรือของออเดอร์เหล่านั้นในหน้าท่าเรือก่อน

## 8. หน้าท่าเรือ (บนมือถือ เน้นเร็ว — คนท่าเรือ / หัวหน้า)

เมนู **ที่ท่าเรือ** — มีช่องเลือกวันที่มุมขวาบน แสดงเฉพาะออเดอร์ของวันนั้นที่ "แพ็คเสร็จ" หรือ "ถึงท่าเรือ" พร้อมส่งขึ้นเรือ

1. **ค้น/เลือกออเดอร์** จากรายการ
2. **เลือกเรือ** ของวันนั้น (ทั้งออเดอร์ไปเรือลำเดียวกัน)
   - ถ้าออเดอร์นี้ยังมียอดค้างชำระ จะขึ้นแบนเนอร์สีเหลือง **"เก็บเงินปลายทาง ฿X (วิธีชำระเงิน)"** ให้เตรียมเก็บเงินจากลูกค้า
3. **แนบรูปหลักฐาน** จำนวนลัง — **ถ่ายรูปด้วยกล้องมือถือก่อน** (แอปกล้องปกติของเครื่อง) แล้วกด **"แนบรูป"** เพื่อเลือกรูปที่เพิ่งถ่ายมาแนบ (อย่างน้อย **1 รูป**, สูงสุด **3 รูป**) รูปจะถูกบีบขนาดในเครื่องให้เล็กก่อนอัปโหลด
   - ระหว่างอัปโหลดรูปจะขึ้นข้อความ "กำลังอัปโหลดรูป กรุณารอสักครู่…" — ปุ่มส่งขึ้นเรือจะกดไม่ได้จนกว่าจะอัปโหลดเสร็จ (กันไม่ให้ออกจากหน้าไปก่อนรูปบันทึกเสร็จ)
4. กด **ส่งขึ้นเรือแล้ว** (ปุ่มจะกดไม่ได้จนกว่าจะเลือกเรือ + มีรูปอย่างน้อย 1 รูป + ไม่มีรูปกำลังอัปโหลดค้างอยู่)
   - สถานะออเดอร์เป็น "ส่งขึ้นเรือแล้ว" และ **เริ่มนับเวลา 48 ชม. สำหรับการเคลม** ของลูกค้าตั้งแต่ตอนนี้

## 9. หน้ารายละเอียดออเดอร์ (ฝั่งทีม)

กดออเดอร์จากงานวันนี้ — เห็นประวัติทั้งหมด: สถานะ, ที่อยู่จัดส่ง, **สรุปลังกระดาษ/ลังโฟม/ชิ้น/รวม**, ลิงก์ลูกค้า, รายการสินค้า, เคลมทุกอัน, รูปตอนแพ็ค, รูปตอนส่งขึ้นเรือ (แยก 2 ชุด), รายการค้างส่งที่เกี่ยวข้อง

- ถ้าออเดอร์ยังมียอดค้างชำระ จะขึ้นแบนเนอร์ **"เก็บเงินปลายทาง ฿X (วิธีชำระเงิน)"** เหมือนหน้าท่าเรือ
- ปุ่ม **"เปลี่ยนเป็น [สถานะถัดไป]"** — เปลี่ยนสถานะออเดอร์ทีละขั้น การขยับไป "ถึงท่าเรือ"/"ส่งขึ้นเรือแล้ว" ต้องเลือกเรือ + มีรูปตอน**ส่งขึ้นเรือ**อย่างน้อย 1 รูปก่อน (รูปตอนแพ็คอย่างเดียวไม่นับ ต้องทำที่หน้าท่าเรือ)

**กล่อง "ลิงก์ลูกค้า":**
- ปุ่ม **คัดลอก** — ก๊อบลิงก์ `/o/<token>` ไปวางให้ลูกค้าใน **LINE**
- ปุ่ม **สร้างลิงก์ใหม่** — ใช้เมื่อลิงก์เดิมหลุดไปที่ไม่ควร; ⚠️ ลิงก์เดิมจะใช้ไม่ได้ทันที ต้องส่งลิงก์ใหม่ให้ลูกค้า

**เขตอันตราย — ลบออเดอร์นี้ (เฉพาะหัวหน้า):**
- ปุ่ม **"ลบออเดอร์นี้"** จะขึ้นเฉพาะบัญชีหัวหน้า (ไม่มีปุ่มนี้สำหรับคนแพ็ค/คนท่าเรือ) — กดแล้วเปิดแผงยืนยัน
- ต้อง**พิมพ์เลขที่ออเดอร์ (makro order no.) ให้ตรงทุกตัวอักษร** ปุ่ม **"ลบถาวร"** ถึงจะกดได้ — พิมพ์ผิดแม้ตัวเดียวก็ยังกดไม่ได้ (ไม่มีการตัดช่องว่าง/ไม่สนตัวพิมพ์เล็กใหญ่ให้)
- ถ้าออเดอร์นี้ **"ส่งขึ้นเรือแล้ว"** จะขึ้นคำเตือนที่แรงกว่าปกติ เพราะลูกค้าอาจเห็นลิงก์/แจ้งเคลมไปแล้ว
- ลบแล้ว **ลบถาวร กู้คืนไม่ได้** — รายการสินค้า รูปหลักฐาน และเคลมที่ผูกกับออเดอร์นี้จะถูกลบไปด้วยทั้งหมด ระบบจะบันทึกประวัติการลบไว้ (ชื่อออเดอร์/ลูกค้า/สถานะ/วันที่ ตอนที่ลบ) แต่ตัวออเดอร์เองจะหายจากระบบถาวร
- นี่คือทางลบออเดอร์แบบปลอดภัยทางเดียวในแอป — ล็อกไว้ที่ระดับฐานข้อมูลด้วย (ไม่ใช่แค่ซ่อนปุ่ม) คนที่ไม่ใช่หัวหน้าจะลบไม่ได้แม้เรียกผ่าน API ตรง ๆ

## 10. คิวเคลม + หน้าเคลียร์เคลม (เฉพาะหัวหน้า)

เมนู **คิวเคลม** — เคลมที่เปิดอยู่ทั้งหมด กรองตามสถานะได้ (ทั้งหมด/เปิด/อนุมัติ/ปฏิเสธ) แถวที่เลยกำหนดเส้นตายจะไฮไลต์สีแดง

กดเคลมเพื่อเปิดหน้าเคลียร์:
- ดู **คำแจ้ง + รูปจากลูกค้า** เทียบกับ **รูปหลักฐานของทีม** (แยกรูปตอนแพ็ค / รูปตอนส่งขึ้นเรือ) และรายการออเดอร์
- เลือก **อนุมัติ** หรือ **ปฏิเสธ**
- ถ้าอนุมัติ เลือกวิธีชดเชย:
  - **คืนเงิน** → ใส่ **จำนวนเงินคืน** — เป็นตัวเลขที่หัวหน้ากรอกเองเพื่อบันทึกไว้ภายใน ไม่ได้คำนวณจากราคาสินค้าใด ๆ ในระบบ (ระบบไม่มีข้อมูลราคาต่อชิ้น) — ทีมไปทำเรื่องคืนเงินจริงในระบบแม็คโครเอง
  - **ส่งชดเชยวันถัดไป** → ระบบสร้างรายการค้างส่งผูกกับวันจัดส่งถัดไปของลูกค้าให้อัตโนมัติ
- ใส่ **โน้ต** (ไม่บังคับ) → กด **บันทึกผล**

## 11. รายการค้างส่ง (backorder) อัตโนมัติ

เกิดขึ้นเองใน 2 กรณี:
1. แม็คโครระบุว่ารายการนั้นส่งไม่ครบ (ของขาด) ตอนนำเข้าออเดอร์ — **ไม่ต้องติ๊กเอง** ระบบอ่านจากไฟล์โดยตรง
2. อนุมัติเคลมแบบ "ส่งชดเชยวันถัดไป"

ระบบผูกรายการค้างส่งเข้ากับ **วันจัดส่งถัดไป** ของลูกค้ารายนั้น (ถ้ายังไม่มีออเดอร์วันถัดไปในระบบ จะพักไว้แล้วผูกอัตโนมัติเมื่อนำเข้าออเดอร์วันนั้น)
วันนั้นหน้าแพ็ค + งานวันนี้จะเตือน "มีของค้างส่ง..." ทีมจัดของแล้วกด **"ส่งแล้ว"** ที่รายการนั้น

## 12. สิ่งที่ลูกค้าเห็น (หน้า `/o/<token>`)

ลูกค้า **ไม่ต้องล็อกอิน** เปิดผ่านลิงก์ที่ทีมส่งใน LINE เท่านั้น (ไม่มีช่องพิมพ์เลขออเดอร์) เห็นเฉพาะออเดอร์ของตัวเอง
มีปุ่มสลับภาษา **EN / ไทย** (ค่าเริ่มต้นอังกฤษ)

ลูกค้าเห็น:
- **ออเดอร์อื่นในวันเดียวกัน** — ถ้าลูกค้ารายนี้ซอยบิลเป็นหลาย PO ที่ส่งวันเดียวกัน (จับคู่ด้วยเบอร์โทรจากไฟล์แม็คโคร) จะขึ้นกล่อง "คุณมีออเดอร์อื่นวันนี้อีก N รายการ" ด้านบนสุด พร้อมสถานะแต่ละ PO และปุ่มกดสลับไปดูได้ทันที ไม่ต้องขอลิงก์ใหม่จากทีม (ลิงก์ของแต่ละ PO ยังเหมือนเดิมทุกอย่าง)
- **สถานะ** (ไทม์ไลน์ 4 ขั้น): Received → Packed → At the pier → Shipped
- **รายการสินค้า** — รหัสสินค้า (Item ID) / ชื่อสินค้า / จำนวนที่สั่ง / จำนวนที่ส่งจริง (ไม่มีราคา) รายการที่ส่งไม่ครบมีป้าย "Short"
- **ของขาด** — แยกเป็นหัวข้อ "Shortages" บอกว่าส่งเท่าไหร่จากที่สั่งเท่าไหร่ (รายการที่ไม่ได้ส่งรอบนี้ ชัดเจน)
- **จำนวนลัง** (กระดาษ / โฟม / **ชิ้น**) และ **เรือลำที่** — ไม่มีตัวเลขรวมที่หน้านี้ (ลูกค้าเห็นแยกเป็นรายชนิด)
- **ยอดที่ต้องชำระ** — โชว์เฉพาะออเดอร์ที่ยังมียอดค้าง (Pay on Delivery ที่ยังไม่จ่าย) ไม่แสดงวิธีชำระเงิน
- **รูปการจัดส่ง** (รูปทั้งตอนแพ็คและตอนส่งขึ้นเรือ เรียงตามเวลา)
- ปุ่ม **แจ้งปัญหา (Report a problem)** — กดแจ้งเคลมรายรายการ: ของขาดในกล่อง / สินค้าเสียหาย / กล่องสูญหาย + ใส่จำนวน + คำอธิบาย + แนบรูปได้สูงสุด 3 รูป
  - ใช้ได้ **ภายใน 48 ชม.** หลังออเดอร์เป็นสถานะ "ส่งขึ้นเรือแล้ว" — พ้นกำหนดปุ่มจะหายและขึ้น "ปิดรับแจ้งปัญหาแล้ว" ลิงก์เองก็หมดอายุพร้อมกัน
- ลูกค้าเห็น **สถานะเคลมของตัวเอง** (รอดำเนินการ / อนุมัติแล้ว / ปฏิเสธ / ปิดเรื่องแล้ว) และวิธีชดเชย

## 13. กติกาสำคัญ (จำไว้)

- **เดดไลน์เคลม 48 ชั่วโมง** นับจากเวลาที่กด "ส่งขึ้นเรือแล้ว" — พ้นแล้วลูกค้าแจ้งเคลมไม่ได้ และลิงก์ลูกค้าหมดอายุ
- **ทั้งออเดอร์ขึ้นเรือลำเดียวกัน** — เลือกเรือทีเดียวจบที่ระดับออเดอร์
- **ไม่มีราคาต่อชิ้นในระบบ** — แม็คโครไม่ส่งไฟล์ราคามาให้ ระบบจึงไม่แสดงราคา/มูลค่าใด ๆ ยกเว้น **ยอดค้างชำระรวม** ที่ดึงมาจากไฟล์ OrderExport ตรง ๆ (สำหรับออเดอร์ Pay on Delivery ที่ยังไม่จ่าย)
- **ของขาด** = อ่านจากไฟล์แม็คโครอัตโนมัติ (ไม่ต้องติ๊กเอง) + สร้างรายการค้างส่งอัตโนมัติ
- **รูปตอนแพ็คไม่จำกัดจำนวน แต่บังคับอย่างน้อย 1 รูป** ถึงจะกด "บันทึก + แพ็คเสร็จ" ได้ (พร้อมมีลังอย่างน้อย 1 ลัง) — **รูปตอนท่าเรือจำกัดสูงสุด 3 รูป บังคับอย่างน้อย 1 รูป** ถึงจะกด "ส่งขึ้นเรือแล้ว" ได้ ทั้งสองจุดบีบขนาดรูปให้เล็กอัตโนมัติก่อนอัปโหลด
- **ข้อมูลถูกลบอัตโนมัติหลัง 30 วัน** — ออเดอร์ + รายการ + รูป + เคลม + ประวัติ ที่เกิน 30 วันถูกลบถาวรทุกคืน (ตี 3) เพื่อความปลอดภัยของข้อมูลลูกค้า ต้องการเก็บย้อนหลังให้พึ่ง backup รายสัปดาห์
- **บทบาท:** อนุมัติ/ปฏิเสธเคลมได้เฉพาะ **หัวหน้า**; คนแพ็คทำหน้าแพ็ค/นำเข้า; คนท่าเรือทำหน้าเรือ/ตั้งค่าเรือ
- **ไม่มีโหมดออฟไลน์** — ต้องมีเน็ตตอนใช้งาน
